# HW 48 — Інтеграція Material UI у React проект

Цей проект демонструє використання **Material UI** у React через Vite.  
Мета: створити інтерфейс із формою додавання карток та списком карток з кнопкою видалення.

- Використання **Material UI** (Buttons, Cards, Typography, Grid, Box)
- **Динамічне додавання та видалення карток** через React state
- Адаптивна верстка за допомогою MUI Grid
- Кнопка **“Видалити”** видаляє конкретну картку зі списку
